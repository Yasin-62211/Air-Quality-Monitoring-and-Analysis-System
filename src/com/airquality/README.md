# 🌍 Air Quality Monitoring & Analysis System

## 📌 Project Overview

The **Air Quality Monitoring & Analysis System** is a Java-based application designed to analyze air quality data and provide an easy-to-understand assessment of air pollution levels.

The system takes air quality parameters such as PM2.5, PM10, CO, and NO2 as input, calculates an Air Quality Index (AQI) value, determines the corresponding air quality status, and provides an alert and environmental recommendation.

This project demonstrates the application of **Object-Oriented Programming (OOP)** and basic data analysis concepts to an environmental problem.

---

## 🎯 Objectives

- Monitor basic air quality parameters.
- Calculate an AQI value from the collected data.
- Classify air quality based on the calculated AQI.
- Provide pollution alerts.
- Generate a simple air quality report.
- Demonstrate the use of Java programming in an environmental application.

---

## ✨ Features

- 📍 Location-based air quality data input
- 🌫️ PM2.5 monitoring
- 🌫️ PM10 monitoring
- 🧪 CO monitoring
- 🧪 NO2 monitoring
- 📊 AQI calculation
- ⚠️ Air quality alert system
- 📄 Automatic report generation
- 💻 Simple command-line interface
